
# DevOps_CI_24BCS204

## Tourist Guide and Hotel Booking System

A simple Python application for managing hotel listings
and calculating booking costs.

## Features
- Display available hotels
- Show prices per night
- Book hotels
- Calculate booking totals
- Validate hotel availability

## Technologies
- Python
- Git
- GitHub
- Jenkins

## Run the application
python src/hotel_booking.py

## Run tests
python -m unittest discover -s tests -v
- Includes hotel listings for Coimbatore and Madurai.
- Version control workflow verified using Git and GitHub.

## Booking Status
Hotel booking requests are confirmed after validation.
