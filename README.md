
# Tourist Guide and Hotel Booking System

**Roll Number:** 24BCS204

## Project Description
A Python application that displays hotel details, checks availability,
allows users to book hotels, and calculates the total booking cost.

## Features
- Display hotel listings and cities
- Show prices per night
- Check hotel availability
- Book hotels
- Calculate total booking costs
- Validate user input

## Technologies
- Python
- Git
- GitHub
- Jenkins

## Run the Application
python src/hotel_booking.py

## Run the Tests
python -m unittest discover -s tests -v

The system provides hotel listings, availability checks, and booking cost calculations.
